# Nextcode Studio website

React + TypeScript + Tailwind CSS (Vite).

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview  # preview the build
```

## Edit content

All text (programs, stats, FAQs, reviews, email) lives in `src/data.ts`.
Brand colours and fonts are in `tailwind.config.js`.
The application form logs to the console in `src/components/Apply.tsx` — connect it to your backend or email service.
